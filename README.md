# 🩺 Ulcer-Health-Risk-Analysis
Ulcer health risk analysis using, Excel, PowerBI, Power Query and DAX

---

## 📌 Overview
The Ulcer Health Risk Analysis Dashboard is an interactive Power BI report designed to analyze patient health data related to ulcer conditions. It provides healthcare professionals and decision-makers with valuable insights into ulcer prevalence, patient demographics, clinical indicators, medication usage, and pain patterns.

By combining key performance indicators (KPIs) with interactive charts and filters, the dashboard allows users to explore relationships between patient age, BMI, hemoglobin levels, ulcer history, ulcer depth, medication usage, and pain severity

---

## 🎯 Objectives
- Analyze the overall distribution of ulcer patients.
- Monitor key health indicators such as BMI and hemoglobin levels.
- Examine ulcer depth and severity across patients.
- Identify pain patterns associated with ulcer conditions.
- Support data-driven clinical and healthcare management decisions.

---

## 📊 Dashboard Features
**KPI Cards**

- Total Patients
- Average BMI
- Average Hemoglobin Level
- Average Age Comparison
- Average Ulcer Size
- Average Pain Severity

---

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

---

## 📈 Key Insights
- Identify the most common ulcer stages and depth levels.
